5660 COLLINS — RESIDENT NOTICES · PUBLIC-ONLY PWA · PHASE 1

READY TO UPLOAD TO GITHUB PAGES

1. BACK UP the existing GitHub repository/index.html before editing.
2. Upload every file and subfolder of this package to the ROOT of the GitHub Pages repository.
3. Open the site's HTTPS URL and test both English and Español.
4. Once Building Management approves the public wording, change "approvalStatus": "draft" to "approvalStatus": "approved" in data/notices.json and commit.
5. On iPhone: Safari > Share > Add to Home Screen > Add.
   On Android: Chrome > menu > Add to Home screen / Install app.
6. To update resident content, edit ONLY data/notices.json and commit. New data loads on the next open, refresh, or approximately every 90 seconds while the site is visible.

IMPORTANT: This version does NOT include private management, Firebase, push notifications or direct auto-import from the three private KB Docs. These are planned for Phase 2. It does NOT silently publish private KB content.
